# Безопасность

Нашёл уязвимость? Не пиши о ней в публичных issues. Открой приватное сообщение через вкладку Security репозитория (Report a vulnerability) или напиши владельцу репозитория.

Что уже сделано: вход по случайному ключу в httpOnly-куке (в базе только хэш), проверка всех данных на сервере, файлы отдаются только владельцу, типы файлов проверяются, CSP, лимиты на создание профилей и размер загрузок.

Приложение для Android работает без сервера: данные лежат только на телефоне, в сеть оно не ходит (кроме видео YouTube после нажатия). Ключ подписи релиза хранится вне репозитория, не коммить `*.jks`, `keystore.properties` и `local.properties`.

Что на тебе при публикации в интернет: HTTPS и `COOKIE_SECURE=1`, прокси перед Node, бэкапы базы и папки загрузок, контакты оператора и политика приватности на твоём домене (для ЕС).
